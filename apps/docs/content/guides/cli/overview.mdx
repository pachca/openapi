# CLI

<CardRow>
  <Card compact title="@pachca/cli" href="https://www.npmjs.com/package/@pachca/cli">npm</Card>
</CardRow>

Официальный CLI для Pachca API: авторизация, сообщения, управление пространством — всё из терминала. Каждый метод API доступен как команда с типизированными флагами, валидацией и подсказками. Нужен Node.js 20+.

## Быстрый старт

<Steps>
  <Step title="Установка">
    ```bash
    npm install -g @pachca/cli
    ```

    Подробнее — [Установка](/guides/cli/installation).
  </Step>
  <Step title="Вход в аккаунт">
    Если вход выполняете вы сами, достаточно подтвердить его в браузере, получать токен заранее не нужно. Так могут войти администраторы, а остальные сотрудники — если настройка пространства разрешает им персональные токены. Подробнее — в разделе [Кто может создавать токены](/api/authorization#kto-mozhet-sozdavat-tokeny).

    Для CI и агентов, где подтверждать некому, создайте токен заранее: персональный на странице **Интеграции** > **API** или токен бота в его карточке. Передайте его переменной окружения `PACHCA_TOKEN`: CLI возьмёт токен из неё, отдельный вход не нужен.

    ```bash
    # Подтверждение в браузере
    pachca auth login

    # CI и агенты: готовый токен в переменной окружения
    export PACHCA_TOKEN=YOUR_ACCESS_TOKEN
    ```

    Подробнее — [Авторизация в CLI](/guides/cli/authentication).
  </Step>
  <Step title="Первый запрос">
    ```bash
    pachca users list

    #  ID     TITLE      FIRST_NAME   LAST_NAME   EMAIL
    #  1234   Менеджер   Иван         Иванов      ivan@example.com
    #  5678   Дизайнер   Мария        Петрова     maria@example.com
    ```

    Готово. Это типизированная команда. Тот же запрос можно сделать и напрямую через `pachca api` — оба способа описаны в разделе [Способы работы](#sposoby-raboty).
  </Step>
</Steps>

Без установки — разовый запуск через `npx`, токен передаётся флагом:

```bash
npx -y @pachca/cli users list --token YOUR_ACCESS_TOKEN
```

## Способы работы

С CLI можно работать двумя способами. Основной — типизированные команды: так написаны все примеры в документации и интеграции. В дополнение есть команда `pachca api` для прямых запросов и встроенного справочника по API.

### Типизированные команды

Каждый метод API — отдельная команда `pachca <секция> <действие>` с флагами, валидацией и подсказками. Справка по любой команде — флаг `--help`:

```bash
pachca messages create --entity-id 123 --content "Привет"  # отправить сообщение
pachca messages create --help  # справка по этой команде
pachca commands  # список всех команд
```

Пропущенные обязательные флаги CLI запросит интерактивно. Флаг `-o json` переключает вывод в машиночитаемый JSON.

Все команды со всеми флагами — в разделе [Справочник команд](/guides/cli/commands).

### Прямые запросы

Команда `pachca api` отправляет прямой HTTP-запрос к любому методу — для нестандартных вызовов и отладки. Она же работает как встроенный справочник по API: список методов и справку по каждому (параметры, тело, пример) можно получить прямо в терминале, **не открывая сайт документации**. Справочник работает и до входа, поэтому особенно удобен агентам:

```bash
pachca api POST /messages -F 'message[entity_id]=123' -f 'message[content]=Привет'  # тот же запрос
pachca api POST /messages --describe  # справка по тому же методу
pachca api ls  # список всех методов
```

Подробнее — [Прямые запросы](/guides/cli/api-requests).
