# Экспорт сообщений

<Warning>Доступно только на тарифе **Корпорация**. Для работы с экспортом токен должен иметь скоупы `chat_exports:write` и `chat_exports:read`, доступные только владельцу пространства.</Warning>

Экспорт сообщений — это архив c файлами в формате `JSON`, где собраны все сообщения из всех чатов, которые были созданы в вашем пространстве.

В экспорте вам будут доступны все сообщения из открытых, закрытых и архивных чатов, в том числе треды. У каждого сообщения будет указан автор, время отправки, текст, список реакций на это сообщение.

Так же, в экспорте есть личные переписки, но в ограниченном формате. В них указан автор сообщения, время отправки, но нет контента сообщений и тредов. Эти данные полезны для оценки вовлеченность сотрудников их активности или оценке нагрузки на каждого из участников команды.

На основе выгрузки можно замерять количество сообщений и реакций в общих чатах. Так можно рассчитать Engagment Rate и улучшать корп. культуру/коммуникацию среди сотрудников. Ещё можно подсчитывать количество активных чатов и смотреть, насколько много в компании ведется обсуждений.

## Как это работает

<Steps>
  <Step title="Запросите экспорт">
    При запросе экспорта можно настроить период, за который вы хотите получить данные, но не более 45 дней. И можете добавить ID-чатов, из которых вы хотите получить экспорт. Если вам нужны данные за период дольше 45 дней, то по завершении одной выгрузки, можно запросить следующую с новым диапазоном дат.

    При запросе экспорта важно учитывать следующие ограничения:

    - выгружаются все чаты, в том числе архивные и личные без контента сообщений
    - не выгружаются треды в личных сообщениях
    - не учитываются вложения
    - не отражаются пересланные сообщения
    - максимальный период одной выгрузки: 45 дней (при запросе с указанием конкретных чатов - 366 дней), а дата конца не может быть раньше даты начала: на другой период метод отвечает `422` с кодом `invalid_date_range`
    - максимальное количество запрашиваемых чатов (при указании): 50, на больший список метод отвечает `422` с кодом `too_long`
    - даты начала и конца периода передаются в формате YYYY-MM-DD, иначе метод отвечает `422` с кодом `invalid`
    - следующий запрос экспорта пространство может отправить через 90 секунд после предыдущего независимо от того, завершился он или ещё идёт, а более ранний вернёт `422` с кодом `rate_limit`
    - запрос, отклонённый из-за параметров (периода, списка чатов или формата даты), эту паузу не запускает

    Для запроса экспорта используйте метод [Экспорт сообщений](POST /chats/exports).

    Экспорт выполняется асинхронно. Чтобы сразу получить номер выгрузки, передайте заголовок `Prefer: return=representation`: ответ придёт со статусом `202` и номером в `data.id`. Без заголовка ответ пустой, со статусом `204`. SDK, CLI и нода n8n передают этот заголовок сами.

    Когда архив готов, на указанный `webhook_url` будет отправлен `JSON` с информацией о готовом экспорте. Поле необязательно: без него о готовности узнает заказавший — из письма и уведомления в Пачке, а программа может проверять готовность по номеру из ответа.

    Адрес должен быть доступен из интернета по `http` или `https`. Иначе запрос отклоняется с `422` и кодом `invalid_webhook_url`, и экспорт не запускается. Адрес с ошибкой в записи, без хоста, с другой схемой или с IP-адресом из приватного диапазона отклоняется до паузы между запросами экспорта, и исправленный запрос можно отправить сразу. Имя хоста, которое не резолвится или ведёт на приватный адрес (например, `localhost`), проверяется уже после того, как запрос запустил эту паузу, поэтому исправленный запрос получится отправить только через 90 секунд. Если вебхук не пришёл, проверьте доступность адреса снаружи.

    <SchemaBlock name="ExportWebhookPayload" title="Вебхук о готовой выгрузке" />
  </Step>

  <Step title="Скачайте готовый архив">
    Возьмите номер выгрузки из ответа на запрос или из поля `export_id` вебхука и выполните запрос на скачивание архива сообщений, указав его в `URL` запроса.

    Для скачивания архива используйте метод [Скачать архив экспорта](GET /chats/exports/{id}). Пока архив собирается, метод отвечает `404` с кодом `export_file_not_found`: повторите запрос позже.
  </Step>

  <Step title="Изучите структуру архива">
    Архив представляет собой папки, где каждая папка соответствует чату в вашем пространстве. Название папки состоит из имени чата и его `ID`, например: `Design_12925828`. Внутри папки будут `JSON`-файлы, которые соответствуют дате переписки. Каждый день — отдельный файл.

    Дополнительно, рядом с папками будет находиться список чатов, которые попали в экспорт. Список чатов представлен файлом `chats.json`. Список не создается, если при запросе экспорта было указано `skip_chats_file` как `true`.
