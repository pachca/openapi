---

Отправь сообщение в Пачку через API по странице https://dev.pachca.com/guides/quickstart.md. Скачай её: `curl -sL https://dev.pachca.com/guides/quickstart.md`. Инструмент для веба отдаёт пересказ, бери его, только если curl не сработал. Если и он не открыл страницу, остановись и скажи.

Если у тебя нет инструментов Пачки, сначала подключи её по странице https://dev.pachca.com/guides/mcp/connect.md, потом я пришлю тебе этот запрос ещё раз.

1. Спроси меня, что, куда и от кого написать: от бота с каким названием или от меня.
2. Для бота выпусти токен с правами из шага «Получите токен», а если такого бота у меня нет, сначала создай его без входящего вебхука. Токен запиши только в `.env` как `PACHCA_TOKEN`, файл добавь в `.gitignore`. Если пишу я, свой токен положу туда сам: скажи, где его выпустить.
3. Проверь токен запросом из шага «Проверьте токен», ошибку разбери там же. Значение токена не печатай.
4. Создай беседу для проверки, добавь в неё бота, если пишет он, и отправь туда текст запросом из шага «Отправьте сообщение». Проверь, что он пришёл.
5. После моего «да» отправь текст туда, куда я сказал: идентификатор найди по шагу «Выберите, куда писать», бота в беседу или канал сначала добавь.
6. Перечисли, что создано, дай команду повторной отправки и скажи, как отозвать токен и убрать беседу.

Если мешают права, роль или настройки пространства, не обходи: скажи, что мешает и кто это изменит. Чего не можешь сам, например выполнить запрос, дай мне готовыми командами.
