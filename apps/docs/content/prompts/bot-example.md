Запусти у меня бота с открытым кодом со страницы примеров.

1. Спроси, какого бота запустить и как его назвать.
2. Скачай в эту папку его код по ссылке из раздела бота. По README создай бота и беседу для проверки с ботом.
3. События передавай боту пересылкой по разделу «Разработка без публичного адреса» второй страницы. Событие о новых сотрудниках и домены ссылок включай после моего «да»: с ними бот пишет коллегам.
4. Токен и Signing secret держи только в `.env`, добавленном в `.gitignore`. Остальные ключи я впишу сам: назови их.
5. Запусти бота и пересылку в фоне и проверь сценарий из README в беседе. Для Welcome Bot отправь событие о новом сотруднике сам, с моим идентификатором.
6. Перечисли, что создано, как запустить снова и удалить бота.

Бота для ссылок создаёт только администратор или владелец. Если мешают права, роль или настройки пространства, не обходи: скажи, что мешает и кто это изменит. Чего не можешь сам, дай мне готовыми командами.
