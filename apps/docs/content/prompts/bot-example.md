---

Запусти бота с открытым кодом по странице https://dev.pachca.com/guides/bots/examples.md. Скачай её: `curl -sL https://dev.pachca.com/guides/bots/examples.md`. Инструмент для веба отдаёт пересказ, бери его, только если curl не сработал. Если и он не открыл страницу, остановись и скажи.

Если у тебя нет инструментов Пачки, сначала подключи её по странице https://dev.pachca.com/guides/mcp/connect.md, потом я пришлю тебе этот запрос ещё раз.

1. Спроси меня, какого бота запустить и как его назвать.
2. Скачай в эту папку код бота по ссылке из его раздела. По README создай бота и беседу для проверки, добавь в неё бота.
3. События Пачки передавай боту пересылкой по разделу «Разработка без публичного адреса» страницы https://dev.pachca.com/guides/webhook/deploy.md, её тоже скачай через curl. Событие о новых сотрудниках и домены ссылок включай после моего «да»: с ними бот пишет коллегам.
4. Токен и Signing secret бота запиши только в `.env`, файл добавь в `.gitignore`. Другие ключи и токены я впишу сам: назови их.
5. Запусти в фоне бота и пересылку, проверь сценарий из README в беседе. Для Welcome Bot отправь сам событие о новом сотруднике с моим идентификатором.
6. Перечисли, что создано, как снова запустить бота и как удалить его.

Unfurl-бота создаёт только администратор или владелец. Если мешают права, роль или настройки пространства, не обходи: скажи, что мешает и кто это изменит. Чего не можешь сам, например настроить вебхук в GitHub, дай мне готовыми командами.
