Напиши скрипт на Pachca CLI под мою задачу.

1. Спроси, что должен делать скрипт и где его запускать: здесь или в CI.
2. Запусти `pachca doctor`. Если он не проходит, настрой CLI по странице https://dev.pachca.com/guides/cli/installation.md. Токен для CI я положу в `.env` как `PACHCA_TOKEN`, добавь `.env` в `.gitignore`.
3. Напиши скрипт по разделам «Неинтерактивный режим», «Exit codes» и «Ошибки». Флаги сверяй по `--help`, вывод бери с `-o json`, списки целиком с `--all`.
4. Без флага `--apply` скрипт выполняет меняющие команды с `--dry-run` из раздела «Предпросмотр запроса». Флаг `--force` ставь только на удаление, о котором я просил.
5. Запусти скрипт без `--apply` и покажи, что изменится. После моего «да» запусти с `--apply` и проверь результат. Упавшую команду, которая создаёт или отправляет, повторяй, только убедившись, что она не прошла.
6. Дай команды запуска и скажи, как отменить сделанное.

Чего не можешь сам, например войти в CLI через браузер, дай мне готовыми командами.
