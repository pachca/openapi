Настрой Pachca CLI на этой машине.

1. Спроси, ставить CLI глобально или запускать через `npx -y @pachca/cli`. Если вход в CLI уже есть, спроси, оставить его или добавить профиль по разделу «Профили».
2. Проверь версию Node.js по странице, поставь CLI и проверь его версию.
3. Команду из раздела «Вход через браузер» дай мне: я запущу её в своём терминале и подтвержу вход в браузере.
4. Если вход через браузер не подходит или CLI нужен под ботом, войдём по разделу «Вход готовым токеном»: токен я создам сам, а ты дай команду, которая передаст его из буфера обмена. Токен в чате не проси.
5. Проверь всё командой `pachca doctor` и скажи, под кем я вошёл и что не прошло.
6. Перечисли изменения и как всё убрать по разделу «Удаление».

Чего не можешь сам, например поставить пакет через `sudo`, дай мне готовыми командами.
