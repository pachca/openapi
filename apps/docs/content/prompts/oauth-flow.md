2. Создай бота с авторизацией: адрес возврата http://localhost:3000/oauth/callback, доступ из пункта 1. Токену бота дай право отправлять сообщения.
3. Секрет и токен бота запиши только в `.env`, файл добавь в `.gitignore`.
4. В этой папке доведи до рабочего сервер из раздела «Пример на TypeScript» с адресом возврата из пункта 2: токены сотрудников храни в памяти, в журнал пиши, кто дал согласие, при запуске сервер отправляет кнопку мне в личные сообщения.

6. Перечисли, что создано, как запустить сервер снова и удалить бота.
