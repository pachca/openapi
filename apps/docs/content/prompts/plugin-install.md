Шаги бери из раздела своей программы. Если плагин в ней не работает, остановись и скажи.

3. Если плагина нет, поставь его по разделу.
4. Ручной сервер оставь или убери по разделу программы, скиллы из команды — по разделу «Установка скиллов» второй страницы, скачай её: `curl -sL https://dev.pachca.com/guides/ai-agents/skills.md`. Удаляй только после моего «да», а до этого скажи, каким ещё программам эти скиллы нужны.
