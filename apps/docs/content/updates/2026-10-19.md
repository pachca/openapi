title: 'Номер выгрузки в ответе и аватар бота'
---

Метод [Экспорт сообщений](POST /chats/exports) может сразу вернуть номер выгрузки: с заголовком `Prefer: return=representation` он отвечает статусом `202` и номером в теле. По этому номеру архив забирают методом [Скачать архив экспорта](GET /chats/exports/{id}), когда сборка закончится, и вебхук для этого не нужен. SDK, CLI и нода n8n передают заголовок сами. Подробнее — в разделе [Экспорт сообщений](/guides/export).

Аватар бота теперь можно поставить и убрать через API. Это доступно тем, кто может редактировать настройки бота.

Были добавлены новые методы:

- [Загрузка аватара бота](PUT /bots/{id}/avatar)
- [Удаление аватара бота](DELETE /bots/{id}/avatar)

Обмен кода на токен и отзыв токена описаны в справочнике методов, рядом с остальными методами API. В SDK у них появились свои методы, а ссылку для кнопки авторизации и пару PKCE SDK собирает сам. Как пройти авторизацию от имени сотрудника целиком — в разделе [Получение токена](/guides/oauth/flow).

- [Обмен кода на токен](POST /oauth/token)
- [Отзыв токена](POST /oauth/revoke)

Ещё изменения:

- Метод [Информация о боте](GET /bots/{id}) отдаёт адрес входящего вебхука, секрет подписи исходящего и тело последнего запроса на входящий вебхук. Они приходят токену со скоупом `bots:write`, если вы можете управлять токенами бота.
- Бесплатное пространство отправляет ограниченное число писем-приглашений за сутки. Подробнее — на странице [Лимиты](/api/limits).
- Редактирование сотрудника применяется целиком: если новая почта занята, остальные поля тоже не меняются.
- В тег можно добавить только бота, которого может добавить в чат любой сотрудник. Подробнее — в разделе [Бот в тегах](/guides/bots/settings#bot-v-tegah).
- Метод [Новый чат](POST /chats) возвращает идентификаторы сотрудников, которых не удалось добавить в чат.
- Ответ `429` методов API при превышении лимитов приходит в `JSON`, как остальные ошибки. Подробнее — на странице [Лимиты](/api/limits).
- Поиск в методе [Список сотрудников](GET /users) сообщает, что страницы закончились. Подробнее — на странице [Пагинация](/api/pagination#spisok-sotrudnikov-s-parametrom-query).
- Списки и поиск отвечают ошибкой на нецелое число записей на странице. Подробнее — на странице [Пагинация](/api/pagination).
- В части пространств метод [Получение подписи, ключа и других параметров](POST /uploads) отдаёт другой набор полей формы. SDK, CLI и нода n8n передают в форме те поля, которые пришли. Подробнее — на странице [Загрузка файлов](/api/file-uploads).
- При блокировке отправки сообщений за перегрузку ответ сообщает, сколько осталось до снятия блокировки. Подробнее — на странице [Лимиты](/api/limits).
- Метод [Информация о токене](GET /oauth/token/info) отдаёт дату входа из CLI или выдачи доступа внешнему приложению.
