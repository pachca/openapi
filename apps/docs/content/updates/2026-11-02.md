Страницы об AI-агентах и MCP перестроены. [Обзор AI-агентов](/guides/ai-agents/overview) начинается с того, что такое MCP-сервер, CLI и скиллы и зачем они нужны. [Подключение к MCP](/guides/mcp/connect) начинается с четырёх шагов: сервер по адресу, вход в Пачку, скиллы одной командой и проверка. Дальше на странице один список программ с командами для каждой.

[Скиллы](/guides/ai-agents/skills) и [Плагин](/guides/ai-agents/plugin) переехали из раздела MCP в «AI-агенты»: скиллы работают с MCP-сервером, CLI, API и SDK, а плагин стал необязательным способом поставить сервер и скиллы одной установкой.

Ещё изменения:

- Установка скиллов начинается с одной команды и готовой просьбы к агенту. Подробнее — в разделе [Установка скиллов](/guides/ai-agents/skills#ustanovka-skillov).
- На странице CLI появился раздел [AI-агент с CLI](/guides/cli/overview#ai-agent-s-cli).
