# Удаление секрета приложения

**Метод**: `DELETE`

**Путь**: `/apps/{id}/secrets/{name}`

> **Скоуп:** `apps:write`

Удаляет секрет. Удаление секрета, которого нет, не ошибка.

Метод доступен владельцу и администраторам пространства. Раздел «Кастомные приложения» доступен пространствам из бета-программы, записаться можно на https://pachca.com/custom-apps.

## Параметры

### Path параметры

- `id: string` (required) — Идентификатор приложения
- `name: string` (required) — Имя секрета


## Пример запроса

```bash
curl -X DELETE "https://api.pachca.com/api/shared/v1/apps/k3x9q2m7a1bz/secrets/API_KEY" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Ответы

### 204: There is no content to send for this request, but the headers may be useful. 

### 401: Access is unauthorized.

**Схема ответа при ошибке:** `OAuthError`. Поля и коды описаны в разделе [Ошибки](/api/errors).

**Пример ответа:**

```json
{
  "error": "invalid_token",
  "error_description": "Access token is missing"
}
```
