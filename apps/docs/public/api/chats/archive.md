# Архивация чата

**Метод**: `PUT`

**Путь**: `/chats/{id}/archive`

> **Скоуп:** `chats:archive`

Отправляет беседу или канал в архив: чат пропадает из списков у всех участников, новые сообщения в него не принимаются, а история сохраняется.

Архивация не только замораживает чат. Из него исключаются все гости, а теги от него отвязываются. Приведённые тегом сотрудники при этом остаются обычными участниками, но состав чата больше не поддерживается сам. Метод [Разархивация чата](/api/chats/unarchive) не возвращает ни гостей, ни привязку тегов.

Треды, заведённые в чате, остаются открытыми: писать в них можно и после архивации.

Личный чат и тред в архив не отправляются. Повторная архивация уже архивного чата отвечает `403`.

## Параметры

### Path параметры

- `id: integer, int32` (required) — Идентификатор чата


## Пример запроса

```bash
curl -X PUT "https://api.pachca.com/api/shared/v1/chats/334/archive" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Ответы

### 204: There is no content to send for this request, but the headers may be useful. 

### 401: Access is unauthorized.

**Схема ответа при ошибке:** `OAuthError`. Поля и коды описаны в разделе [Ошибки](/api/errors).

**Пример ответа:**

```json
{
  "error": "invalid_token",
  "error_description": "Access token is missing"
}
```

### 402: Client error

**Схема ответа при ошибке:** `ApiError`. Поля и коды описаны в разделе [Ошибки](/api/errors).

**Пример ответа:**

```json

      "message": "Поле не может быть пустым",

}
```
