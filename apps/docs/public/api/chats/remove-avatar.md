# Удаление аватара чата

**Метод**: `DELETE`

**Путь**: `/chats/{id}/avatar`

> **Скоуп:** `chats:update`

Убирает аватар беседы или канала. Доступно тому же, кому доступна [Загрузка аватара чата](/api/chats/update-avatar).

Если аватара не было, ответ всё равно `204`.

## Параметры

### Path параметры

- `id: integer, int32` (required) — Идентификатор чата


## Пример запроса

```bash
curl -X DELETE "https://api.pachca.com/api/shared/v1/chats/334/avatar" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```
