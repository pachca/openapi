# Добавление участников

**Метод**: `POST`

**Путь**: `/chats/{id}/members`

> **Скоуп:** `chat_members:write`

Добавляет сотрудников и ботов в беседу, канал или тред. Бота добавляют так же, как сотрудника: его `id` в `member_ids`. В канале он получает роль редактора, а в беседе становится обычным участником — и только после этого может туда писать.

Добавлять участников могут сотрудники и боты. Гостю и мульти-гостю метод отвечает `403`, как и в интерфейсе, какая бы роль в чате у них ни была.

Роль в чате назначается в момент добавления: владелец пространства и администратор становятся администраторами чата, остальные — обычными участниками. Дальше роль в чате сама не пересчитывается: повышение сотрудника в пространстве не меняет его роль там, где он уже состоит. Менять роль нужно методом [Редактирование роли участника](/api/members/update).

Тех, кто уже состоит в чате, метод пропускает молча и ошибкой это не считает. А вот неизвестный или неактивный идентификатор останавливает весь запрос: метод отвечает `404` и перечисляет такие значения, никто при этом не добавляется.

Бота добавляет только тот, кому это разрешает настройка бота «Кто может добавлять бота в чаты» — подробнее в разделе [Настройки бота](/guides/bots/settings#kto-mozhet-dobavlyat-bota-v-chaty). Если в `member_ids` есть бот, которого вам добавлять нельзя, метод не добавляет никого и отвечает `403` с кодом `bot_add_denied` и идентификаторами таких ботов в `value`. Если в том же запросе есть и неизвестный идентификатор, ответ — `404` с обеими ошибками.

Бота с настройкой «Ограничить одним чатом», который уже состоит в другой беседе или канале, метод тоже не добавляет: ответ `409` с кодом `single_chat_bot_occupied` и идентификаторами таких ботов в `value`, никто из запроса не добавляется. В треды такого бота добавлять можно.

Добавить сразу целый отдел удобнее тегом — [Добавление тегов](/api/members/add-group-tags): тогда состав чата поддерживается сам.

## Параметры

### Path параметры

- `id: integer, int32` (required) — Идентификатор чата (беседа, канал или чат треда)


## Тело запроса

**Обязательно**

Формат: `application/json`

### Схема

- `member_ids: array of integer` (required) — Массив идентификаторов пользователей, которые станут участниками. Пример: `[186,187]`
- `silent: boolean` (default: false) — При `true` в чат не приходит системное сообщение о добавлении, а добавленные сотрудники не получают письмо с приглашением. Сообщение бывает только в закрытой беседе, письмо — в беседах и каналах у тех, кто не отключил такие письма. В треде параметр ничего не меняет. Пример: `true`

### Пример

```json
{
  "member_ids": [
    186,
    187
  ],
  "silent": true
}
```

## Пример запроса

```bash
curl "https://api.pachca.com/api/shared/v1/chats/334/members" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "member_ids": [
    186,
    187
  ],
  "silent": true
}'
```
