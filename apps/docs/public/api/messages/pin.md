# Закрепление сообщения

**Метод**: `POST`

**Путь**: `/messages/{id}/pin`

> **Скоуп:** `pins:write`

Закрепляет сообщение в шапке беседы или канала, где его видят все участники. Ограничения на число закреплённых сообщений нет.

В тредах метод не работает. Уже закреплённое сообщение отвечает `409`, а удалённое — `422`.

## Параметры

### Path параметры

- `id: integer, int32` (required) — Идентификатор сообщения


## Пример запроса

```bash
curl -X POST "https://api.pachca.com/api/shared/v1/messages/194275/pin" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Ответы

### 204: There is no content to send for this request, but the headers may be useful. 

### 401: Access is unauthorized.

**Схема ответа при ошибке:** `OAuthError`. Поля и коды описаны в разделе [Ошибки](/api/errors).

**Пример ответа:**

```json
{
  "error": "invalid_token",
  "error_description": "Access token is missing"
}
```
