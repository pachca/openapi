# Новый свой статус

**Метод**: `PUT`

**Путь**: `/profile/status`

> **Скоуп:** `profile_status:write`

Ставит статус владельцу токена: эмодзи, подпись и, если нужно, срок. Метод доступен и боту — статус появится в карточке самого бота.

Режим «Нет на месте» включается этим же методом, флагом `is_away`. В `away_message` кладут текст, который увидят в профиле и при попытке написать или упомянуть. Когда срок из `expires_at` истекает, статус снимается целиком, вместе с режимом и этим текстом.

Перезаписываются только переданные поля. Чтобы продлить текущий статус, достаточно прислать один `expires_at`.

Срок, названный словами («до трёх», «до конца дня»), — это `expires_at`, а не часть подписи. Считается он в часовом поясе сотрудника, а пояс приходит в методе [Свой профиль](/api/profile/get).

Эмодзи и подпись обязательны, только когда статуса ещё нет. Эмодзи должен быть ровно один, без текста вокруг, а подпись — не длиннее 50 символов.

## Тело запроса

**Обязательно**

Формат: `application/json`

### Схема

- `status: object` (required)
  - `emoji: string` — Emoji символ статуса. Обязателен, если статуса ещё нет. Пример: `"🎮"`
  - `title: string` (max length: 50) — Текст статуса. Обязателен, если статуса ещё нет. Пример: `"Очень занят"`
  - `expires_at: date-time` — Срок жизни статуса (ISO-8601). Смещение вида `+03:00` учитывается, время без смещения считается UTC. Пример: `"2024-04-08T10:00:00.000Z"`
  - `is_away: boolean` — Режим «Нет на месте». Пример: `true`
  - `away_message: string` (max length: 1024) — Текст сообщения при режиме «Нет на месте». Отображается в профиле и при личных сообщениях/упоминаниях. Пример: `"Вернусь после 15:00"`

### Пример

```json
{
  "status": {
    "emoji": "🎮",
    "title": "Очень занят",
    "expires_at": "2024-04-08T10:00:00.000Z",
    "is_away": true,
    "away_message": "Вернусь после 15:00"
  }
}
```

## Пример запроса

```bash
curl -X PUT "https://api.pachca.com/api/shared/v1/profile/status" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "status": {
    "emoji": "🎮",
    "title": "Очень занят",
    "expires_at": "2024-04-08T10:00:00.000Z",
    "is_away": true,
    "away_message": "Вернусь после 15:00"
  }
}'
```

## Ответы

### 200: The request has succeeded.

**Схема ответа:**

- `data: object` (required) — Статус пользователя
  - `emoji: string` (required) — Emoji символ статуса. Пример: `"🎮"`
  - `title: string` (required, max length: 50) — Текст статуса. Пример: `"Очень занят"`
  - `expires_at: date-time` (required, nullable) — Срок жизни статуса (ISO-8601, UTC+0) в формате YYYY-MM-DDThh:mm:ss.sssZ. `null`, если срок не задан — такой статус не сбрасывается автоматически. Пример: `"2024-04-08T10:00:00.000Z"`
  - `is_away: boolean` (required) — Режим «Нет на месте». Пример: `false`
  - `away_message: object` (required, nullable) — Сообщение при режиме «Нет на месте». Отображается в профиле пользователя, а также при отправке ему личного сообщения или упоминании в чате. `null`, если текст не задан.
    - `text: string` (required, max length: 1024) — Текст сообщения. Пример: `"Я в отпуске до 15 апреля. По срочным вопросам обращайтесь к @ivanov."`

**Пример ответа:**

```json
{
  "data": {
    "emoji": "🎮",
    "title": "Очень занят",
    "expires_at": "2024-04-08T10:00:00.000Z",
    "is_away": false,
    "away_message": {
      "text": "Я в отпуске до 15 апреля. По срочным вопросам обращайтесь к @ivanov."
    }
  }
}
```
