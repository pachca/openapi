# Редактирование напоминания

**Метод**: `PUT`

**Путь**: `/tasks/{id}`

> **Скоуп:** `tasks:update`

Меняет напоминание: перезаписываются только переданные поля.

Передать напоминание другому сотруднику — это тоже правка. `performer_ids` заменяет список ответственных целиком: прочитайте текущий список методом [Информация о напоминании](/api/tasks/get) и передайте всех, кто остаётся, вместе с новым ответственным.

Выполненное напоминание закрывают этим же методом: `status: "done"` ставит галочку и оставляет напоминание в списке, `status: "undone"` возвращает его в работу.

Доступно автору и ответственным. Участник чата, где висит напоминание, его видит, но менять не может. Привязку к чату изменить нельзя: чтобы перевесить напоминание в другой чат, удалите его и создайте заново с нужным `chat_id`.

## Параметры

### Path параметры

- `id: integer, int32` (required) — Идентификатор напоминания


## Тело запроса

**Обязательно**

Формат: `application/json`

### Схема

- `task: object` (required) — Собранный объект параметров обновляемого напоминания
  - `kind: string` — Тип
    Значения: `call` — Позвонить контакту, `meeting` — Встреча, `reminder` — Простое напоминание, `event` — Событие, `email` — Написать письмо
  - `content: string` — Описание. До 40 000 байт в UTF-8. Пример: `"Забрать со склада 21 заказ"`
  - `due_at: date-time` — Срок выполнения напоминания (ISO-8601). Смещение вида `+03:00` учитывается, время без смещения считается UTC. Секунды отбрасываются: срок встаёт на начало минуты. Исключение — ровно 23:59:59: такое напоминание создаётся на весь день, без указания времени. Пример: `"2020-06-05T12:00:00.000+03:00"`
  - `priority: integer, int32` (min: 1, max: 3) — Приоритет: 1, 2 (важно) или 3 (очень важно). Пример: `2`
  - `performer_ids: array of integer` — Массив идентификаторов пользователей, привязываемых к напоминанию как «ответственные». Список заменяет прежний целиком. Пример: `[12]`
  - `status: string` — Статус
    Значения: `done` — Выполнено, `undone` — Активно
  - `all_day: boolean` — Напоминание на весь день. При правке поле не применяется: напоминание на весь день задаёт срок `due_at` ровно на 23:59:59 нужного дня с местным смещением сотрудника, например `2026-10-29T23:59:59+03:00`. Пример: `false`
  - `done_at: date-time` — Дата и время выполнения напоминания (ISO-8601). Смещение вида `+03:00` учитывается, время без смещения считается UTC. Значение, которое не удалось разобрать, отметку о выполнении снимает: ответ придёт успешный, а в нём `done_at` будет `null`. Пример: `"2020-06-05T12:00:00.000Z"`
  - `custom_properties: array of object` — Задаваемые дополнительные поля
    - `id: integer, int32` (required) — Идентификатор поля. Пример: `78`
    - `value: string` (required) — Устанавливаемое значение. Пример: `"Синий склад"`

### Пример

```json
{
  "task": {
    "kind": "reminder",
    "content": "Забрать со склада 21 заказ",
    "due_at": "2020-06-05T12:00:00.000+03:00",
    "priority": 2,
    "performer_ids": [
      12
    ],
    "status": "done",
    "all_day": false,
    "done_at": "2020-06-05T12:00:00.000Z",
    "custom_properties": [
      {
        "id": 78,
        "value": "Синий склад"
      }
    ]
  }
}
```

## Пример запроса

```bash
curl -X PUT "https://api.pachca.com/api/shared/v1/tasks/22283" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "task": {
    "kind": "reminder",
    "content": "Забрать со склада 21 заказ",
    "due_at": "2020-06-05T12:00:00.000+03:00",
    "priority": 2,
    "performer_ids": [
      12
    ],
    "status": "done",
    "all_day": false,
    "done_at": "2020-06-05T12:00:00.000Z",
    "custom_properties": [
      {
        "id": 78,
        "value": "Синий склад"
      }
    ]
  }
}'
```

## Ответы

### 200: The request has succeeded.

**Схема ответа:**

- `data: object` (required) — Напоминание
  - `id: integer, int32` (required) — Идентификатор напоминания. Пример: `22283`
  - `kind: string` (required) — Тип
    Значения: `call` — Позвонить контакту, `meeting` — Встреча, `reminder` — Простое напоминание, `event` — Событие, `email` — Написать письмо
  - `content: string` (required) — Описание. Пример: `"Забрать со склада 21 заказ"`
  - `due_at: date-time` (required, nullable) — Срок выполнения напоминания (ISO-8601, UTC+0) в формате YYYY-MM-DDThh:mm:ss.sssZ. `null`, если срок не задан. Пример: `"2020-06-05T09:00:00.000Z"`
  - `priority: integer, int32` (required) — Приоритет. Пример: `2`
  - `user_id: integer, int32` (required) — Идентификатор пользователя-создателя напоминания. Пример: `12`
  - `chat_id: integer, int32` (required, nullable) — Идентификатор чата, к которому привязано напоминание. `null`, если напоминание не привязано к чату. Пример: `334`
  - `status: string` (required) — Статус напоминания
    Значения: `done` — Выполнено, `undone` — Активно
  - `created_at: date-time` (required) — Дата и время создания напоминания (ISO-8601, UTC+0) в формате YYYY-MM-DDThh:mm:ss.sssZ. Пример: `"2020-06-04T10:37:57.000Z"`
  - `performer_ids: array of integer` (required) — Массив идентификаторов пользователей, привязанных к напоминанию как «ответственные». Пример: `[12]`
  - `all_day: boolean` (required) — Напоминание на весь день: `true`, если при создании передан `all_day: true` или срок стоит ровно на 23:59:59. Веб-версия Пачки показывает напоминание без времени только по такому сроку, а при другом времени срока показывает это время. Пример: `false`
  - `custom_properties: array of object` (required) — Дополнительные поля напоминания
    - `id: integer, int32` (required) — Идентификатор поля. Пример: `1678`
    - `name: string` (required, max length: 32) — Название поля. Пример: `"Город"`
    - `data_type: string` (required) — Тип поля
      Значения: `string` — Строковое значение, `number` — Числовое значение, `date` — Дата, `link` — Ссылка
    - `value: string` (required, nullable, max length: 768) — Значение. Возвращается `null`, если поле не заполнено. Число передаётся строкой, дата — в формате ISO 8601. Пример: `"Санкт-Петербург"`

**Пример ответа:**

{
  "data": {
    "id": 22283,
    "kind": "reminder",
    "content": "Забрать со склада 21 заказ",
    "due_at": "2020-06-05T09:00:00.000Z",
    "priority": 2,
    "user_id": 12,
    "chat_id": 334,
    "status": "undone",

      {
        "id": 1678,

    ]
