# Новый тред

**Метод**: `POST`

**Путь**: `/messages/{id}/thread`

> **Скоуп:** `threads:create`

Заводит тред под сообщением — место, где обсуждают сказанное, не засоряя ленту чата. Тред — это отдельный доступ: в него можно позвать сотрудника, не открывая ему сам чат, и он увидит только тред и родительское сообщение. Если обсуждать нужно тему, а не сообщение, заводите тред методом [Новый самостоятельный тред](/api/threads/create).

В новый тред сразу попадают тот, кто его создал, автор сообщения, все, кто ставил на сообщение реакции, и участники чата, включившие уведомления о тредах. Упомянутых в родительском сообщении — и поимённо, и тегом — добавляет фоновая задача сразу после создания, поэтому в первом ответе их может ещё не быть. Общие упоминания вроде `@all` в тред никого не приводят, а упомянутого, которого нет в самом чате, тред не подхватит.

Пустой тред разговором ещё не является: сразу отправьте в него первое сообщение методом [Новое сообщение](/api/messages/create) с `entity_type: "thread"` и `id` треда из ответа. Названия у треда нет, и удалить его нельзя ни через API, ни в приложении.

Если у сообщения уже был создан тред, то в ответе на запрос вернётся информация об уже созданном ранее треде. Новый тред заводит только участник чата: тому, кто видит открытую беседу или канал, но не состоит в них, метод отвечает `403`, а уже созданный тред возвращает. Но чтобы просто прочитать тред, метод не нужен: идентификатор существующего треда приходит в поле `thread` самого сообщения. Тред под сообщением, которое само лежит в треде, завести нельзя: вложенных тредов в Пачке нет, и метод отвечает `400` с кодом `thread_message`.

## Параметры

### Path параметры

- `id: integer, int32` (required) — Идентификатор сообщения


## Пример запроса

```bash
curl -X POST "https://api.pachca.com/api/shared/v1/messages/154332686/thread" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Ответы

### 201: The request has succeeded and a new resource has been created as a result.

**Схема ответа:**

- `data: object` (required) — Тред
  - `id: integer, int64` (required) — Идентификатор треда. Чтобы написать в тред, передайте его в `entity_id` метода [Новое сообщение](/api/messages/create) с `entity_type: "thread"`. Пример: `265142`
  - `chat_id: integer, int64` (required) — Идентификатор чата треда. По нему читают сообщения треда методом [Список сообщений чата](/api/messages/list) и работают с его участниками. Пример: `2637266155`
  - `message_id: integer, int64` (required, nullable) — Идентификатор сообщения, к которому был создан тред. `null` для самостоятельного треда, созданного без привязки к сообщению. Пример: `154332686`
  - `message_chat_id: integer, int64` (required, nullable) — Идентификатор чата сообщения. `null` для самостоятельного треда, созданного без привязки к сообщению. Пример: `2637266154`
  - `updated_at: date-time` (required) — Дата и время обновления треда (ISO-8601, UTC+0) в формате YYYY-MM-DDThh:mm:ss.sssZ. Пример: `"2023-02-01T19:20:47.204Z"`

**Пример ответа:**

```json
{
  "data": {
    "id": 265142,
    "chat_id": 2637266155,
    "message_id": 154332686,
    "message_chat_id": 2637266154,
    "updated_at": "2023-02-01T19:20:47.204Z"
  }
}
```
