# Плагин и скиллы

Плагин «Пачка» ставит в одну команду всё, что нужно агенту для работы в Пачке: подключение к [MCP-серверу](/guides/ai-agents/mcp), скиллы и команды.

Скиллы — знание о том, как правильно делать задачи в Пачке: куда писать и что подтверждать, как найти и пересказать обсуждение, какой токен выбрать и почему не хватает прав. Справочник по аргументам агент берёт из описаний инструментов MCP-сервера, `pachca <команда> --help` и страниц методов, поэтому скиллы его не повторяют и ссылаются на документацию. Скиллы работают с любым способом подключения: MCP-сервером, CLI или API.

## Claude Code

```bash
claude plugin marketplace add pachca/openapi
claude plugin install pachca@pachca
```

Внутри Claude Code то же делают команды `/plugin marketplace add pachca/openapi` и `/plugin install pachca@pachca`. После установки выполните `/mcp`, выберите сервер Пачки из плагина и войдите через браузер, как при [подключении вручную](/guides/ai-agents/mcp-connect#claude-code). Если сервер уже добавлен командой `claude mcp add`, уберите его командой `claude mcp remove pachca`, чтобы инструменты не задвоились.

Свежую версию плагина ставит `claude plugin update pachca@pachca`. Чтобы обновления приходили сами, включите автообновление маркетплейса `pachca` в `/plugin` на вкладке **Marketplaces**.

## Команды плагина

| Команда | Что делает |
|---------|------------|
| `/pachca:catch-up` | Что пропущено за период: упоминания, треды с новыми сообщениями и оживлённые чаты, со ссылками |
| `/pachca:thread-summary` | Пересказ треда целиком: контекст, решения, открытые вопросы и задачи |
| `/pachca:digest` | Дайджест каналов и чатов за период |
| `/pachca:announce` | Объявление в нужном оформлении, черновиком в поле ввода |
| `/pachca:tasks-from` | Задачи по итогам обсуждения с исполнителями и сроками |

Без вашего подтверждения агент ничего не отправляет в чаты и не создаёт задачи для других сотрудников. Дайджест он публикует только в чат, участники которого видят все чаты-источники.

## Codex

```bash
codex plugin marketplace add pachca/openapi
```

Затем установите плагин «Pachca» из каталога плагинов. В Codex плагин подключает MCP-сервер и скиллы, команд в нём нет. Вход в Пачку — через браузер, как при [подключении вручную](/guides/ai-agents/mcp-connect#codex).

## Cursor и другие агенты

Скиллы ставятся в Cursor, Windsurf, Gemini CLI, OpenCode и другие агенты одной командой:

```bash
npx skills add https://dev.pachca.com
```

Команда спросит, какие скиллы и для каких агентов поставить. Из репозитория то же ставит `npx skills add pachca/openapi`. MCP-сервер в этих программах подключается отдельно, токеном в заголовке — см. [Подключение к MCP](/guides/ai-agents/mcp-connect).

## Скиллы

| Скилл | Когда пригодится |
|-------|------------------|
| `pachca` | Подключение через MCP, CLI или API, выбор токена, нет права или инструмента |
| `pachca-messaging` | Написать, ответить в треде, упомянуть, подготовить черновик, запланировать, отправить файл |
| `pachca-search` | Найти обсуждение, чат или сотрудника, пересказать тред, собрать дайджест, поставить задачи по итогам |
| `pachca-admin` | Сотрудники, теги, участники чатов, доступ к API, журнал аудита, экспорт, DLP |
| `pachca-bots` | Бот или интеграция: вебхуки, события, токены и права, кнопки, формы, разворачивание ссылок |
| `pachca-ai-agent` | AI-агент, который живёт в Пачке и отвечает в тредах |
| `pachca-oauth` | Приложение, которое работает от имени каждого сотрудника |
| `pachca-api` | Скрипты, SDK и CI: пагинация, лимиты, ошибки, загрузка файлов |

Каждый скилл — это файл `SKILL.md` с короткими правилами и папка `references/` с подробностями. Агент читает скилл, когда задача подходит под его описание. Скилл `pachca` отдаётся и по адресу [/skill.md](/skill.md): его можно дать агенту ссылкой, как llms.txt.

Скиллы раздаются по стандарту Agent Skills Discovery: индекс лежит по адресу `/.well-known/agent-skills/index.json`. Исходники — в папке [plugins/pachca](https://github.com/pachca/openapi/tree/main/plugins/pachca) репозитория.

- [Agent Skills](https://agentskills.io) — Спецификация формата скиллов
- [Agent Skills Discovery RFC](https://github.com/cloudflare/agent-skills-discovery-rfc) — Протокол обнаружения скиллов
