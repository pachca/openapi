# Готовые примеры реализации

Пошаговые примеры с кодом собраны в двух руководствах:

- [Первый бот](/guides/bots/first-bot) — От создания бота до обработчика: бот получает сообщение и отвечает на него
- [Интерактивный бот](/guides/bots/interactive) — Команда, ответ в тред, кнопки и форма с кодом на TypeScript и Python


Ниже — боты с открытым кодом, которые можно развернуть у себя.

**Сделать с агентом.** Агент скачает код выбранного бота, создаст и настроит его в Пачке, запустит на вашей машине и проверит. Вставьте промпт в чат с ИИ-агентом, к которому [подключена Пачка](/guides/mcp/connect). Агенту, который уже выполняет этот промпт: ниже его копия, начинать заново не нужно.

```text
Запусти у меня бота с открытым кодом со страницы примеров. Скачай страницы документации и делай по ним: `curl -sL https://dev.pachca.com/guides/bots/examples.md https://dev.pachca.com/guides/webhook/deploy.md`. Инструмент для веба отдаёт пересказ, бери его, только если curl не сработал. Если страницы не открылись и так или у тебя нет инструментов Пачки, остановись и скажи.

1. Спроси, какого бота запустить и как его назвать.
2. Скачай в эту папку его код по ссылке из раздела бота. По README создай бота и беседу для проверки с ботом.
3. События передавай боту пересылкой по разделу «Разработка без публичного адреса» второй страницы. Событие о новых сотрудниках и домены ссылок включай после моего «да»: с ними бот пишет коллегам.
4. Токен и Signing secret держи только в `.env`, добавленном в `.gitignore`. Остальные ключи я впишу сам: назови их.
5. Запусти бота и пересылку в фоне и проверь сценарий из README в беседе. Для Welcome Bot отправь событие о новом сотруднике сам, с моим идентификатором.
6. Перечисли, что создано, как запустить снова и удалить бота.

Бота для ссылок создаёт только администратор или владелец. Если мешают права, роль или настройки пространства, не обходи: скажи, что мешает и кто это изменит. Чего не можешь сам, дай мне готовыми командами.
```

## Welcome Bot

Автоматическое приветствие новых сотрудников в личных сообщениях. Три шаблона сообщений: `short`, `default`, `extended`. Развёртывание на Vercel или собственном сервере.

> Подробнее — в статье [Welcome Bot](https://pachca.com/blog/welcome-bot) и на [GitHub](https://github.com/pachca/public-integrations/tree/main/welcome-bot)


## Review Bot

Синхронизация GitHub Pull Requests с чатом Пачки: уведомления о новых PR, статусы проверок, review, workflow runs, авто-упоминание сотрудников. Развёртывание на Яндекс.Облаке или собственном сервере.

> Подробнее — на [GitHub](https://github.com/pachca/review-bot)


## Unfurl-бот

Бот для создания превью ссылок из рабочих сервисов (Trello, Kaiten, Пачка) прямо в чате. Когда сотрудник отправляет ссылку, вместо простого URL все видят информативное превью с заголовком, описанием и изображением.

> Подробнее — в статье [Unfurl-бот](https://pachca.com/blog/unfurl-bot) и на [GitHub](https://github.com/pachca/public-integrations/tree/main/Unfurling-bot)
