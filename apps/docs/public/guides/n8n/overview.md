## Что такое n8n

[n8n](https://n8n.io) — платформа для автоматизации рабочих процессов с открытым исходным кодом. Можно использовать [n8n Cloud](https://app.n8n.cloud/register) или развернуть n8n на собственном сервере. Платформа позволяет создавать интеграции с сервисами без написания кода, используя визуальный редактор с узлами (nodes).

В n8n встроено более 400 готовых узлов для популярных сервисов. Узлы бывают двух типов:

- **Узел триггера** — событие, запускающее рабочий процесс: новое сообщение, нажатие кнопки, обновление статуса и др.
- **Узел действия** — логика после триггера: отправка сообщения в чат, создание задачи, добавление записи в БД и т.д.

## Что можно автоматизировать

- **Уведомления из внешних систем** — принимайте запросы мониторинга, CI/CD или CRM и публикуйте их в нужный чат Пачки ([пример](/guides/n8n/workflows#uvedomleniya-iz-vneshnego-servisa))
- **Бот-ассистент** — подключите AI-агент, который ищет по сообщениям и отвечает на вопросы команды ([пример](/guides/n8n/workflows#ai-assistent))
- **Напоминания** — присылайте в чат список просроченных задач ([пример](/guides/n8n/workflows#napominanie-o-zadachah)) или создавайте напоминание, когда на сообщение ставят выбранную реакцию
- **Согласование** — отправляйте кнопки «Согласовать» и «Отклонить» и обрабатывайте ответ в workflow ([пример](/guides/n8n/workflows#soglasovanie-s-knopkami))
- **Онбординг** — приветствуйте новых участников чата сообщением от бота ([пример](/guides/n8n/workflows#privetstvie-novogo-sotrudnika))
- **Синхронизация данных** — выгружайте сообщения, задачи и события в Google Sheets, Notion или другие сервисы
- **Мониторинг и алерты** — проверяйте состояние сервисов по расписанию и отправляйте алерт в чат при сбое ([пример](/guides/n8n/workflows#monitoring-i-alerty))

Когда хватит входящего вебхука, а когда нужен n8n — в разделе [Входящий вебхук или n8n](/guides/incoming-webhooks#vhodyaschiy-vebhuk-ili-n8n).

## Расширение Пачки

Расширение Пачки для n8n предоставляет два узла:

| Узел | Тип | Описание |
|------|-----|----------|
| **Pachca** | Действие | 19 ресурсов и их операции для работы с API |
| **Pachca Trigger** | Триггер | 19 событий Пачки через исходящий вебхук бота |

- [19 ресурсов](/guides/n8n/resources) — Сообщения, чаты, пользователи, задачи, формы, поиск и другие
- [Триггер с вебхуком](/guides/n8n/trigger) — 19 событий, автоматическая или ручная регистрация вебхука
- [AI-агент](/guides/n8n/advanced) — Используйте Pachca как инструмент AI Agent
- [Автопагинация](/guides/n8n/resources) — Cursor-based пагинация с Return All / Limit


## Что нового в v2.0

Версия 2.0 — полностью автогенерируемая из OpenAPI-спецификации с сохранением 100% обратной совместимости с v1.

- **Новые ресурсы:** Chat Member, Draft, Important Message, OAuth, Read Member, Search, Security (экспорт чата и unfurl — операции внутри Chat и Message)
- **Курсорная пагинация** с Return All / Limit вместо ручного `per`/`page`
- **AI Tool Use** — `usableAsTool: true` для использования с AI Agent
- **Узел Pachca Trigger** с ручной и автоматической регистрацией вебхука и 19 событиями
- **Поисковые выпадающие списки** для полей Chat ID, User ID и Entity ID
- **Загрузка файлов** через S3: по ссылке или из бинарных данных предыдущего узла
- **Полнотекстовый поиск** по сообщениям, чатам и пользователям
- **Журнал безопасности** — журнал аудита действий в пространстве

> Все существующие workflow на v1 продолжают работать без изменений. Подробнее — в разделе [Миграция с v1](/guides/n8n/migration).
