# Список и удаление ботов, права доступа бота, вебхуки видеозвонков

_07 июля 2026_

Появились методы для управления ботами. Метод [Список ботов](GET /bots) возвращает ботов, которые вы можете редактировать, с поиском по имени. Метод [Удаление бота](DELETE /bots/{id}) удаляет бота: прежний токен сразу инвалидируется, бот исключается из чатов, его исходящий вебхук удаляется. Оба метода требуют скоуп `bots:read` и `bots:write` соответственно.

- [Список ботов](GET /bots)
- [Удаление бота](DELETE /bots/{id})

При создании и редактировании бота добавились настройки прав доступа: `who_can_add` — кто может добавлять бота в чаты (`creator`, `creator_admin`, `creator_admin_user`, `anyone`), и `can_edit` — роли, которым, помимо создателя, разрешено редактировать настройки бота (`admin`, `chat_owners`). При создании также можно передать `single_chat` — ограничить бота одной беседой или каналом (личные чаты и треды в ограничение не входят). Все три поля возвращаются в объекте бота.

- [Новый бот](POST /bots)
- [Редактирование бота](PUT /bots/{id})

Появился новый тип исходящего вебхука — события видеозвонков: `video_call_started`, `video_call_finished` и `video_call_recording_ready`. Вебхук приходит для видеозвонков в чатах, где состоит бот. Подробнее о payload — в гайде [Настройка и типы событий](/guides/webhook/events#videozvonki).

В журнале аудита появился тип события `bot_deleted` — удаление бота. Его можно фильтровать параметром `event_key`.

- [Журнал аудита событий](GET /audit_events)

В поиске сотрудников у параметра `sort` появилось значение `creation` — сортировка по дате создания (в дополнение к `by_score` и `alphabetical`).

- [Поиск сотрудников](GET /search/users)

### SDK v1.0.26

- Метод `Список ботов` (`GET /bots`) — список ботов с поиском по имени
- Метод `Удаление бота` (`DELETE /bots/{id}`)
- У бота поля прав доступа: `who_can_add`, `can_edit`, `single_chat`
- Новый payload исходящего вебхука `VideoCallWebhookPayload` и события `video_call_started`, `video_call_finished`, `video_call_recording_ready`
- Журнал аудита: новый тип события `bot_deleted`
- Поиск сотрудников (`GET /search/users`): значение сортировки `creation` (по дате создания)

### CLI v2026.7.0

- `pachca bots list` — список ботов с поиском по имени (`--query`)
- `pachca bots delete` — удаление бота по его `id`
- `pachca bots create` и `bots update` — права доступа бота: `--who-can-add`, `--can-edit`, `--single-chat`
- `pachca search users` — значение сортировки `--sort creation` (по дате создания)

### n8n Node v2.0.14

- Bot: новые операции `Get Many` (список ботов) и `Delete`
- Bot: поля прав доступа `who_can_add`, `can_edit`, `single_chat` в операциях `Create` и `Update`
- Trigger: события видеозвонков `video_call_started`, `video_call_finished`, `video_call_recording_ready`
- User: поиск — опция сортировки `Creation` (по дате создания)

### Generator v1.1.9

- Kotlin SDK: сериализатор union исходящих вебхуков теперь строится по членам union, а не по захардкоженному списку — новый тип payload подхватывается автоматически (чинит компиляцию при добавлении `VideoCallWebhookPayload`)
