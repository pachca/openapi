# 25 июля 2026

_25 июля 2026_

### SDK v1.0.28

- Поле `details` в журнале аудита (`GET /audit_events`) снова читается. Union `AuditEventDetailsUnion` не имеет общего поля-дискриминатора, и генератор подставлял несуществующее поле `type`: Go, C#, Swift и Kotlin падали с ошибкой при разборе всего ответа, Python молча возвращал пустые детали
- Union без дискриминатора теперь разбирается по составу полей payload. В Go у такого union появилось поле `Raw` с исходным JSON
- Python: union с несколькими вариантами выбирается по дискриминатору или по составу полей, а не «первым в списке» — блоки представлений (`ViewBlockUnion`) больше не теряют данные
- В примерах исправлены `callback_id` (`timeoff_reguest_form` → `timeoff_request_form`) и `private_metadata` — значения при открытии формы и в вебхуке о её отправке снова совпадают
- У 32 полей, которые API возвращает как `null`, в описании теперь сказано, когда именно это происходит — сверено с реализацией
- `GET /audit_events`: параметр `end_time` включает верхнюю границу, а не исключает — описание исправлено

### Generator v1.1.10

- Дискриминатор union определяется по всем членам сразу: поле принимается, только если литерал есть у каждого. Раньше сканировался лишь первый член, и union без общего литерала уходил в заведомо сломанную ветку
- Эмиттеры Go, C#, Swift, Kotlin и Python умеют union без дискриминатора — вариант выбирается по составу полей
- Go: инлайновый enum в query-параметре генерируется как `string`, а не `any` (не компилировалось)
- Ключи `x-enum-descriptions`, неоднозначные после замены `:` на `_`, больше не переприсваиваются чужому значению

### CLI v2026.7.2

- `files direct-url`: файл добавляется в форму последним — S3 игнорирует поля после файла, из-за чего загрузка возвращала 403
- Явный `--profile` больше не перебивается переменной `PACHCA_TOKEN`
- Запись больше не повторяется автоматически при 503 — повтор мог создать дубль сообщения
- `chats download-export`: имя файла из `Content-Disposition` не может увести запись за пределы указанной папки
- `-o csv`: ячейки с `=`, `+`, `-`, `@` экранируются, объекты и массивы выводятся как JSON

### n8n Node v2.0.16

- Запись (`POST`/`PATCH`) больше не повторяется автоматически при 5xx — повтор мог отправить сообщение до четырёх раз
- `Bot`: ресурс больше не открывается на необратимой операции `Recreate own bot token`, по умолчанию — `Get Many`
- `User`: у операций со статусом и аватаркой вернулся выбор сотрудника вместо голого числового поля
- Пагинация и поиск чатов: курсор кодируется, доступны результаты со второй страницы и далее
- Триггер: вебхук без `webhook_timestamp` отклоняется, если задан секрет подписи
