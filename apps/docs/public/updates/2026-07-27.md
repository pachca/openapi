# Уточнения в описании API

_27 июля 2026_

Подробнее описали поведение нескольких методов и полей. Работа API не менялась.

Были уточнены следующие методы:

- [Журнал аудита](/api/security/list) — параметр `end_time` включает верхнюю
  границу: выборка за период захватывает событие, попавшее ровно на неё.
- [Мой статус](/api/profile/get-status) и [Статус сотрудника](/api/users/get-status)
  — если статус не установлен, метод отвечает `200` и телом `null`.

Уточнены описания полей моделей:

- У 32 полей описано, в каком случае приходит `null`. Например,
  `last_activity_at` пуст, пока сотрудник ни разу не заходил в Пачку.
- `display_avatar_url` и `display_name` приходят только у сообщений от ботов.
- `name` у реакции заполнено всегда.
- `last_name`, `department` и `title` у незаполненного значения приходят как
  `null` либо как пустая строка.

### SDK v1.0.28

- Поле `details` в журнале аудита (`GET /audit_events`) снова читается. Раньше Go, C#, Swift и Kotlin падали с ошибкой при разборе всего ответа, а Python молча возвращал пустые детали
- Union без общего поля-дискриминатора разбирается по составу полей payload. В Go у такого union появилось поле `Raw` с исходным JSON
- Python: union с несколькими вариантами больше не выбирается «первым в списке» — блоки представлений (`ViewBlockUnion`) не теряют данные
- `display_avatar_url` и `display_name` у сообщения стали опциональными: для сообщений от сотрудников API их не возвращает
- `Reaction.name` больше не nullable
- Уточнены описания полей: у 32 полей сказано, когда API возвращает `null`, и исправлены примеры `callback_id` и `private_metadata` для форм
- Ошибки API снова разбираются в типизированный `ApiError`: поле `payload` описывалось как словарь строк, поэтому ответы с вложенным объектом (ошибки доступа) не десериализовались в Go, Kotlin и C#

### Generator v1.1.10

- Дискриминатор union определяется по всем членам сразу: поле принимается, только если литерал есть у каждого. Раньше сканировался только первый член
- Эмиттеры Go, C#, Swift, Kotlin и Python умеют union без дискриминатора — вариант выбирается по составу полей
- Открытый `additionalProperties` даёт значение произвольного типа, а не строку. В Kotlin для него используется `JsonElement` — `Any` там не сериализуется

### CLI v2026.7.2

- `files direct-url`: файл добавляется в форму последним — S3 игнорирует поля после файла, из-за чего загрузка отклонялась с 400
- Явный `--profile` больше не перебивается переменной `PACHCA_TOKEN`
- Запись больше не повторяется автоматически при 503 — повтор мог создать дубль сообщения
- `chats download-export`: имя файла из `Content-Disposition` не может увести запись за пределы указанной папки
- `-o csv`: ячейки с `=`, `+`, `-`, `@` экранируются, объекты и массивы выводятся как JSON
- `files direct-url` больше не падает при успешной загрузке — S3 отвечает пустым телом, а команда пыталась его разобрать

### n8n Node v2.0.16

- Запись (`POST`/`PATCH`) больше не повторяется автоматически при 5xx — повтор мог отправить сообщение до четырёх раз
- `Bot`: ресурс больше не открывается на необратимой операции `Recreate own bot token`, по умолчанию — `Get Many`
- `User`: у операций со статусом и аватаркой вернулся выбор сотрудника вместо голого числового поля
- Пагинация и поиск чатов: курсор кодируется, доступны результаты со второй страницы и далее
- Триггер: вебхук без `webhook_timestamp` отклоняется, если задан секрет подписи
