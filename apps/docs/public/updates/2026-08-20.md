# Суточный лимит сообщений, отключение 2FA в журнале аудита и сроки ссылок на файлы

_20 августа 2026_

У отправки появился суточный предел — 5 000 сообщений в один чат за скользящие
24 часа, сообщения в тред считаются в чат родительского. При превышении отправка
приостанавливается, и каждая попытка во время паузы её удлиняет. Рядом действует
общий предел по всем чатам сразу — 30 запросов за 5 секунд. Отказ приходит с
`429`, и у этого ответа два вида: суточный предел отдаёт обычную ошибку, а лимит
на частоту запросов — текст, а не `JSON`. Подробнее — в разделах
[Лимиты](/api/limits) и [Ошибки](/api/errors).

- [Новое сообщение](/api/messages/create)

У кнопок сообщения описаны пределы: до 8 в строке, не больше 32 строк и 100 на
сообщение — подробнее в разделе [Кнопки](/guides/buttons). Размер файла `size`
описан 64-битным числом: вложение и запись видеозвонка могут быть больше 2 ГБ.

- [Новое сообщение](/api/messages/create)
- [Редактирование сообщения](/api/messages/update)

Ответ `409` описан у методов, где он возможен, и называет конфликтующее поле в
`errors[].key` — например, `email` при повторном адресе почты сотрудника.

- [Новый сотрудник](/api/users/create)
- [Редактирование сотрудника](/api/users/update)
- [Новый тег](/api/group-tags/create)
- [Редактирование тега](/api/group-tags/update)
- [Закрепить сообщение](/api/messages/pin)

Описан срок действия ссылок на файлы: вложение сообщения — до 7 дней, файл из
формы — 2 часа, и сам файл хранится сутки после отправки. Удаление сообщения
стирает вложения из хранилища сразу. Подробнее — в разделах
[Загрузка файлов](/api/file-uploads) и [Обработка форм](/guides/forms/handling).

- [Информация о сообщении](/api/messages/get)

Журнал аудита пополнился событием `user_2fa_disabled` — сотрудник отключил себе
двухфакторную аутентификацию.

- [Журнал аудита событий](/api/security/list)

Вложенный `.html`-файл Пачка показывает просмотром прямо в переписке. Скрипты в
нём не выполняются, а картинки и стили нужно вшивать в документ — подробнее в
разделе [Markdown и документы](/guides/ai-agents/markdown).

В поле `content` исходящего вебхука приходят цитаты и списки, а подчёркивание не
отражается — у него нет markdown-синтаксиса. Описания
[блоков формы](/guides/forms/blocks), напоминаний и [разметки](/guides/markdown)
сверены с поведением API: уточнены изначальный выбор пункта, пределы длины и
границы значений. На странице [Лимиты](/api/limits) описан отдельный предел для
выборки списка чатов номером страницы.

### n8n Node v2.1.1

- `Security`: фильтр событий пополнился значением `User 2fa Disabled` — сотрудник отключил себе двухфакторную аутентификацию
- `Trigger`: у payload о заполнении формы описано значение блока `file_input` — массив объектов с полями `name`, `size` и `url`, где ссылка действует 2 часа
- `Message`: размер файла `size` описан 64-битным числом, поэтому вложение больше 2 ГБ помещается в поле

### CLI v2026.8.3

- `pachca security list` — флаг `--event-key` принимает значение `user_2fa_disabled`
- `pachca api POST /messages --spec` — размер файла `size` описан 64-битным числом, а у ссылки `url` указан срок действия до 7 дней
- `pachca api POST /views/open --spec` — у радиокнопки блока `radio` изначальный выбор задаётся полем `checked`, как у чекбоксов, а не `selected`
- `pachca tasks create --spec` и `pachca tasks update --spec` — у `priority` показаны допустимые границы 1–3, которые проверяет API
- `pachca api --spec` показывает ответ `409` у методов сотрудника, тега и закрепления сообщения и ответ `429` у `POST /messages` — суточный предел сообщений в чат

### SDK v1.4.0

- Поле `size` у файла сообщения и у записи видеозвонка описано 64-битным числом — размер файла может превышать 2 ГБ. Методы `Новое сообщение` (`POST /messages`), `Редактирование сообщения` (`PUT /messages/{id}`), payload вебхука о видеозвонке
- Описан срок действия ссылок на файлы: `url` у файла сообщения действует до 7 дней, а значение блока `file_input` в `data` вебхука о заполнении формы приходит массивом объектов с полями `name`, `size` и `url`, где ссылка живёт 2 часа
- Поле `selected` у радиокнопки блока `radio` переименовано в `checked` — так его называет форма. Модель `ViewBlockSelectableOption`, метод `Открыть форму` (`POST /views/open`)
- Поле `options` у блоков `select`, `radio` и `checkbox` стало обязательным — форма без пунктов отклоняется валидацией
- Поле `description` у пункта выпадающего списка — модель `ViewBlockSelectOption`
- Предел длины `url` у кнопки сообщения — 1024 символа, и предел массива `buttons` — 32 строки
- Значение `user_2fa_disabled` в перечислении типов аудит-событий
- Границы `priority` в методах напоминаний — от 1 до 3
- Предел длины `value` у пункта блоков `select`, `radio` и `checkbox` — 255 символов
