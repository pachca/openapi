_22 сентября 2026_

### n8n Node v2.1.4

- `Message`: подсказка к полю `Entity ID` называет пользователя, а не сотрудника — личное сообщение можно отправить и боту

### CLI v2026.9.2

- `api POST /messages --describe`: личное сообщение адресуется идентификатором пользователя, в том числе бота, а имя без `@` и упоминание внутри кода упоминанием не считаются
- `api POST /messages --describe`: тред под сообщением, у которого его ещё нет, сначала создают, а таблицу, чек-лист или диаграмму прикладывают файлом `.md`
- `api POST /drafts --describe`: отправка сообщения черновик не удаляет — через API его убирают отдельным вызовом
- `api POST /chats --describe` и `api POST /messages/{id}/thread --describe`: для разговора на одну тему указан самостоятельный тред
- `pachca messages create`: подсказка к `--entity-id` называет пользователя, а не сотрудника — личное сообщение можно отправить и боту
- `api POST /messages/{id}/thread` и `api GET /chats/{id} --describe`: прочитать существующий тред можно без создания, а переписку чата возвращает список сообщений
