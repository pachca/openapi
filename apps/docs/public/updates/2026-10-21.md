# Вход по QR-коду в журнале аудита

_21 октября 2026_

Журнал аудита записывает вход в мобильное приложение по QR-коду с экрана компьютера. Появились события `login_grant_created`, `login_grant_approved` и `login_grant_denied`: код открыт, вход подтверждён или отклонён. У события `user_login` при таком входе в деталях приходят способ входа и идентификатор, который связывает все события одного входа. Подробнее — в разделе [Вход по QR-коду в журнале](/guides/audit-events#vhod-po-qr-kodu-v-zhurnale).

Ещё изменения:

- Метод [Поиск сообщений](/api/search/list-messages) ищет строгой фразой запрос, целиком взятый в кавычки, в том числе типографские `«…»`, `“…”` или `„…“`.

Были обновлены следующие методы:

- [Журнал аудита событий](/api/security/list)
- [Поиск сообщений](/api/search/list-messages)

### n8n Node v2.2.1

- `Security`: фильтр событий пополнился событиями входа по QR-коду — `Login Grant Created`, `Login Grant Approved` и `Login Grant Denied`

### CLI v2026.10.2

- `pachca security list` — флаг `--event-key` принимает события входа по QR-коду: `login_grant_created`, `login_grant_approved` и `login_grant_denied`

### SDK-библиотеки v1.6.1

- Типы аудит-событий `login_grant_created`, `login_grant_approved` и `login_grant_denied` и модели их деталей с моделью устройства `AuditLoginGrantDevice` и перечислениями `AuditLoginGrantDevicePlatform` и `AuditLoginGrantDenyReason`
- Модель `AuditDetailsUserLoginQr` — детали `user_login` при входе по QR-коду
