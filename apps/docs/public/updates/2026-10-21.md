# MCP-сервер Пачки и вход по QR-коду в журнале аудита

_21 октября 2026_

Появился MCP-сервер Пачки: Claude Code, Cursor и другие программы с AI-агентами подключаются по адресу `https://mcp.pachca.com/mcp` и получают инструмент на каждый метод API. Права те же, что в API, а программу, подключённую через браузер, видно в списке «Авторизации» на странице «API». Подробнее — в разделе [MCP-сервер](/guides/ai-agents/mcp).

Журнал аудита записывает вход в мобильное приложение по QR-коду с экрана компьютера. Появились события `login_grant_created`, `login_grant_approved` и `login_grant_denied`: код открыт, вход подтверждён или отклонён. У события `user_login` при таком входе в деталях приходят способ входа и идентификатор, который связывает все события одного входа. Подробнее — в разделе [Вход по QR-коду в журнале](/guides/audit-events#vhod-po-qr-kodu-v-zhurnale).

Скиллы для AI-агентов написаны заново: теперь это знание о том, как правильно делать задачи в Пачке. Куда писать и что подтверждать, как найти и пересказать обсуждение, какой токен выбрать и почему не хватает прав. Справочник по аргументам агент берёт из описаний инструментов MCP-сервера и `pachca <команда> --help`. В Claude Code, приложении Claude, Codex, GitHub Copilot и Cursor скиллы вместе с MCP-сервером ставит плагин «Пачка», в нём же команды для пересказа треда, дайджеста, объявления и задач по итогам обсуждения. В SourceCraft Code Assistant, OpenCode и другие агенты восемь скиллов ставятся без плагина. Страницы «Сценарии», файл Arazzo и команда `pachca guide` убраны, их роль взяли скиллы. Подробнее — в разделе [Плагин и скиллы](/guides/ai-agents/plugin).

Ещё изменения:

- Метод [Поиск сообщений](/api/search/list-messages) ищет строгой фразой запрос, целиком взятый в кавычки, в том числе типографские `«…»`, `“…”` или `„…“`.
- Метод [Скачивание файла](/api/files/get) отдаёт любое вложение, которое видно токену: защищённое — запросу из безопасного контура, остальные — всегда. Подробнее — в разделе [Ссылка на скачивание](/api/file-uploads#ssylka-na-skachivanie).

### n8n Node v2.2.1

- `Security`: фильтр событий пополнился событиями входа по QR-коду — `Login Grant Created`, `Login Grant Approved` и `Login Grant Denied`

### CLI v2026.10.2

- `pachca security list` — флаг `--event-key` принимает события входа по QR-коду: `login_grant_created`, `login_grant_approved` и `login_grant_denied`

### SDK v1.6.1

- Типы аудит-событий `login_grant_created`, `login_grant_approved` и `login_grant_denied` и модели их деталей с моделью устройства `AuditLoginGrantDevice` и перечислениями `AuditLoginGrantDevicePlatform` и `AuditLoginGrantDenyReason`
