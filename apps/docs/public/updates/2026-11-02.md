# Подключение к MCP в четыре шага, скиллы и плагин в разделе «AI-агенты»

_02 ноября 2026_

Страницы об AI-агентах и MCP перестроены. [Обзор AI-агентов](/guides/ai-agents/overview) начинается с того, что такое MCP-сервер, CLI и скиллы и зачем они нужны. [Подключение к MCP](/guides/mcp/connect) начинается с четырёх шагов: сервер по адресу, вход в Пачку, скиллы одной командой и проверка. Дальше на странице один список программ с командами для каждой.

[Скиллы](/guides/ai-agents/skills) и [Плагин](/guides/ai-agents/plugin) переехали из раздела MCP в «AI-агенты»: скиллы работают с MCP-сервером, CLI, API и SDK, а плагин стал необязательным способом поставить сервер и скиллы одной установкой.

Ещё изменения:

- Установка скиллов начинается с одной команды и готовой просьбы к агенту. Подробнее — в разделе [Установка скиллов](/guides/ai-agents/skills#ustanovka-skillov).
- На странице CLI появился раздел [AI-агент с CLI](/guides/cli/overview#ai-agent-s-cli).

### Плагин и скиллы v1.0.6

- `pachca-search` пересказывает тред и разбирает его по просьбе: на «что поправить по треду» даёт замечания нумерованным списком со статусом по коду, на «в чём проблема» объясняет простыми словами, что сломалось, как воспроизвести, что уже пробовали и что пока неизвестно. Команда `summarize-thread` убрана.
- Скилл `pachca-watch-thread` вместо команды `watch-thread`: агент берёт его по просьбе «следи за тредом», а в Claude Code его можно вызвать и явно, набрав `/pachca:pachca-watch-thread`. Скилл ставится и без плагина через `npx skills`.
- Команда `post-changes` убрана: пост об изменениях агент пишет по обычной просьбе со скиллом `pachca-messaging`, в стиле прошлых постов чата, черновиком и со скриншотами результата
- `pachca-messaging`: на «ответь в тред» со ссылкой на сообщение агент пишет в тред под этим сообщением, а не цитатой в чат
- `pachca-messaging`: упоминание сотрудника, которого вы не называли, агент согласует до отправки, а после таймаута сначала читает чат и не отправляет сообщение второй раз
- `pachca`: в облачной сессии Claude Code нет плагина и его скиллов, а Пачка доступна через коннектор приложения Claude или сервер из `.mcp.json` репозитория
