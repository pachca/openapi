# События бота в терминале и на локальном обработчике без публичного адреса

_10 ноября 2026_

Команда CLI `pachca bots listen-events` получает события бота в реальном времени без публичного адреса вебхука. Без флагов она выводит события в терминал строкой JSON, а с флагом `--forward-to` пересылает их на локальный обработчик так же, как исходящий вебхук, с подписью и ответом на отправку формы. Туннель для разработки поэтому не нужен. Нужен токен бота с правом `webhooks:events:read` и включённая настройка **Сохранять историю событий**. Подробнее — в разделе [Через CLI](/guides/webhook/polling#cherez-cli).

Ещё изменения:

- Разработка бота на своей машине с этой командой описана в разделе [Разработка без публичного адреса](/guides/webhook/deploy#razrabotka-bez-publichnogo-adresa).
- Для CLI нужен Node.js 20.3.0 или новее.

### Плагин и скиллы v1.0.11

- `pachca-bots`: события из потока агент принимает командой `pachca bots listen-events`, а с `--forward-to` подключает к ним локальный обработчик без кода
- Инструкция подключения CLI указывает минимальную версию Node.js 20.3.0

### CLI v2026.11.2

- `pachca bots listen-events` получает события бота в реальном времени без публичного адреса: выводит JSONL в терминал или пересылает их на локальный обработчик, как исходящий вебхук, с подписью, свежим `webhook_timestamp` и ответом на отправку формы. Запись удаляется из истории после ответа 2xx.
- Для запуска CLI требуется Node.js 20.3.0 или новее
