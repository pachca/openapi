# @pachca/create-app

Новое приложение Пачки одной командой:

```bash
npm create @pachca/app@latest notes -- --name "Заметки"
```

Команда создаёт папку, пишет `package.json` с `@pachca/app-sdk` и `@pachca/app-react` своей версии (релиз у трёх пакетов один), ставит зависимости тем менеджером, которым её запустили, и копирует шаблон из установленного `@pachca/app-sdk`. Название из `--name` получит приложение при первой загрузке, без флага это имя папки.

Дальше всё делается в папке приложения:

```bash
cd notes
npx pachca-app check
npx pachca-app ship
```

Как устроено приложение, написано в `AGENTS.md` папки.
