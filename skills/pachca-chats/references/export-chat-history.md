### Экспорт истории чата

1. Запроси экспорт и возьми номер выгрузки из `data.id`:
   ```bash
   pachca chats request-export --start-at=<YYYY-MM-DD> --end-at=<YYYY-MM-DD>
   ```
   > `start_at`, `end_at` (YYYY-MM-DD). Номер приходит с заголовком `Prefer: return=representation` и ответом `202`, CLI и SDK шлют его сами. Без заголовка ответ `204` без тела

2. Дождись готовности архива: пока он собирается, скачивание отвечает `404` с кодом `export_file_not_found`. О готовности сообщает и вебхук на `webhook_url` с `"event": "ready"` и `export_id`

3. Скачай файл экспорта:
   ```bash
   pachca chats download-export <id>
   ```
   > Сервер вернёт 302, HTTP-клиент скачает файл автоматически

> Экспорт доступен только Владельцу на тарифе «Корпорация». Макс период: 45 дней (366 при указании конкретных чатов). Следующий экспорт пространство может заказать через 90 секунд после предыдущего.
